# Paula Cesare - Lawyer Website

Professional website for **Paula Cesare de Oliveira**, a Brazilian lawyer specialized in **Social Security Law** (*Direito Previdenciário*). Designed to attract new clients through online presence, lead capture, and — soon — AI-powered chat triage.

**Live site:** [luan-felipe-rodrigues.github.io/site-paula-advogada](https://luan-felipe-rodrigues.github.io/site-paula-advogada/)

---

## Tech Stack

| Layer | Tool |
|---|---|
| Frontend | HTML5 + CSS3 + Vanilla JavaScript |
| Hosting | GitHub Pages (free, HTTPS) |
| Database | Supabase (PostgreSQL, free tier) |
| Lead capture | RPC function `submit_lead` via Supabase REST API |

## Features

- Responsive mobile-first design with olive green palette
- Interactive service accordion with detailed descriptions
- Contact modal with form connected to database
- Scroll animations and smooth navigation
- WhatsApp direct link integration
- Toast notifications for form feedback

## Sobre o Projeto (PT-BR)

Site profissional para a advogada **Paula Cesare de Oliveira**, especializada em **Direito Previdenciário**. O objetivo é captar novos clientes por presença online.

### Funcionalidades

- Design responsivo com paleta verde oliva
- Acordeão interativo de serviços (aposentadoria por idade, tempo de contribuição, invalidez, revisão de benefícios)
- Formulário de contato conectado ao banco de dados (Supabase)
- Integração direta com WhatsApp
- Animações suaves e navegação inteligente

### Seções do site

1. **Hero** — "Sua Aposentadoria com Segurança" + botões WhatsApp e Email
2. **Sobre** — Quem é Paula Cesare + estatísticas
3. **Serviços** — Áreas de atuação em formato acordeão
4. **Diferenciais** — Benefícios com ícones
5. **Contato** — Telefone, WhatsApp, email + modal de formulário
